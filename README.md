# ChordScope Studio — 曲のコード進行・キー・BPM解析ツール

Python (`librosa` / `scipy` / `yt-dlp` / `mido` / `FastAPI`) を用いた、高精度なコード進行・キー（調）・BPM推定ツールです。
専用ローカルWebスタジオ画面での**再生連動リアルタイムハイライト表示**と、**CLIからの直接解析・MIDI出力**の両方に対応しています。

---

## 主な機能

1. **YouTube / ストリーミングURL ＆ ローカル音声ファイル対応**
   - `yt-dlp` と同梱 `ffmpeg` により、YouTubeのURLを貼り付けるだけで音声ストリームを取得・解析します。
   - 手元の音声・動画ファイル（MP3, WAV, M4A, FLAC, MP4など）のドラッグ＆ドロップにも対応しています。
2. **7th・テンション・sus4・dim・aug・オンコード（分数コード）判定**
   - HPSS（調波・打楽器分離）によりドラム成分を除去した上で、CQT（定Q変換）クロマグラムと低域ベース音クロマ（C1〜C3）を別々に抽出。
   - メジャー/マイナーの三和音だけでなく、`7`, `M7`, `m7`, `m7(b5)`, `dim7`, `sus4`, `7sus4`, `aug`, `6`, `m6`, `add9` およびオンコード（`G/B`, `C/E` など）をビタビアルゴリズムで平滑化して推定します。
3. **キー（調）・ディグリー（ローマ数字）・BPM・A4チューニング偏差の自動推定**
   - Krumhansl-Kessler / Temperley プロファイルによるキー＆平行調判定と、キーに対する各コードのディグリー（`IVM7`, `V7`, `iiim7`, `vim7` など）を自動算出します。
4. **再生連動ハイライト ＆ 2オクターブ鍵盤ビジュアライザー**
   - 波形シークバー付きのプレイヤーで曲を再生すると、現在鳴っているコード・前のコード・次のコードと、ピアノ鍵盤上の構成音（ベース音＋コードトーン）がリアルタイムにハイライトされます。
   - 耳コピに便利な再生速度変更（`0.5x` 〜 `1.25x`）や、ワンクリック移調（カポタスト変換）機能を搭載しています。
5. **DAW用 Standard MIDI File (`.mid`) 出力**
   - 解析されたコードネームマーカー、BPMテンポ情報、およびベース＋エレピボイシングのノート情報を含んだ `.mid` ファイルをワンクリックでダウンロードできます。

## 起動方法

### 事前準備

Python 3.10 以上を用意し、プロジェクトのルートで依存パッケージをインストールしてください。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### 1. ローカルWebスタジオ画面を起動する場合

```bash
python app.py
```

起動後、ブラウザで **http://127.0.0.1:8000** を開いてください。

### 2. コマンドライン（CLI）から直接解析・MIDI出力する場合

```bash
python cli.py "https://www.youtube.com/watch?v=..." --midi output.mid
```
（URLの代わりに手元の `.mp3` や `.wav` ファイルのパスも指定できます）
